# Site Bar à Chats (Exercice)

**Contexte :** Exercice de développement Web
**Catégorie :** Web Dev
**Date de début :** 17 septembre 2025
**Notions abordées :** HTML, JavaScript, PHP, SEO, Bootstrap

## Description du Projet
Pour mettre en pratique les notions vues en cours tout au long de l'année, nous avons réalisé un site web fictif pour un bar à thème. Mon choix s'est porté sur un bar à chats baptisé "Neptune's Cats Bar". 

Les documents et rendus (5 au total) retracent l'avancée progressive de ce projet, couvrant les différentes technologies abordées en formation.

*(Le projet est détaillé et terminé sur le portfolio en ligne).*
